## 🆘 Plan B - Solución de Problemas

### Si la app no carga:
1. [ ] Presionar 'R' en la terminal para recargar
2. [ ] Si no funciona, Ctrl+C y `npm start` de nuevo
3. [ ] Último recurso: Mostrar screenshots/video pregrabado

### Si el tour no aparece:
1. [ ] Recargar la página (Ctrl+R)
2. [ ] Verificar URL: http://localhost:8081
3. [ ] Navegar manualmente sin tour

### Si hay lag o lentitud:
1. [ ] Cerrar otras aplicaciones
2. [ ] Cerrar pestañas innecesarias del navegador
3. [ ] Continuar con demostración más lenta

### Si se cae internet:
1. [ ] La app funciona offline
2. [ ] Continuar con funcionalidades locales
3. [ ] Explicar que se sincroniza después

### Si hay preguntas técnicas difíciles:
1. [ ] "Excelente pregunta, la anoto"
2. [ ] "Le envío la respuesta detallada después"
3. [ ] "Nuestro equipo técnico puede explicar mejor"
